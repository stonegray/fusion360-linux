CompatReview — Cross-Distro Compatibility Report

Cross-distro compatibility findings for the Fusion360 Linux Launcher.

File Issue Severity Recommendation
install-scripts/00-common.sh Distro detection fails on non-standard distros (NixOS, Void, etc.) without a generic fallback Medium Add a 'Manual' path or allow overriding INSTALL_CMD and PKGS
runtime-scripts/fusion-gray-overlay-event-killer.sh Strictly X11-dependent (xprop, xdotool). Fails silently on Wayland Critical Check WAYLAND_DISPLAY and abort with helpful message; add command -v guards
runtime-scripts/launcher-functions.sh DPI detection lacks GNOME support, falls back to 144 DPI on high-res GNOME without xrdb Medium Use gsettings get org.gnome.desktop.interface scaling-factor
install-scripts/00-defaults.sh Hardcoded ~/.local/share/Steam for Proton search Low Search common paths or use STEAM_COMPAT_CLIENT_INSTALL_PATH
40-fusion-installer.sh, launcher-functions.sh Calls kbuildsycoca blindly; messy errors on non-KDE Low Use command -v wrapper consistently
install.sh, uninstall.sh Root guard present but sudo env vars checked inconsistently Low Standardize on a helper to check/request sudo access
