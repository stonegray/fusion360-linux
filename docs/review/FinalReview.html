Critical — Will Crash or Corrupt Data

1. install.sh broken paths CRIT

install.sh:63 sources runtime-scripts/uninstall-select.sh — file is at src/runtime/. install.sh:101 executes same stale path for protocol registration. Both --uninstall and protocol registration source a non-existent file → crash.

Fix: s/runtime-scripts/src\/runtime/g on both lines.

2. 37-config.sh undefined variables CRIT

$GE_PROTON and $fusion_root at lines 20, 24, 28 are never defined in the file or its parent scope. Config will contain PROTON= and FUSION_ROOT= (empty). With set -u, the shell aborts. Also: missing printf %q bash-version fallback that save_config() has.

Fix: Use $COMPAT_DIR + find for GE_PROTON, compute fusion_root from $PFX_DIR.

3. Distro package resolution broken CRIT

00-common.sh detect_distro() groups aliases (ubuntu|neon|pop|...) under one case, but the file lookup uses literal $ID. Pop!_OS, Neon, Mint, Manjaro, Endeavour, SUSE all silently get zero packages. generic.txt is empty.

Fix: Map aliases to canonical distro names for file lookup, or add $ID.txt for every alias.

4. Python UI silently drops 2 config keys CRIT

launcher-config-user-interface.py CONFIG_KEYS missing FUSION_STAGING_WRITECOPY and FUSION_HEAP_DELAY_FREE. Every save via Python UI silently deletes these keys from the config.

Fix: Add both keys to CONFIG_KEYS list.

5. parse_args rejects no-arg invocation CRIT

doctor/00-common.sh parse_args has a *) default case that prints "Unknown option" and exits. But when $1 is empty (./doctor.sh with no args), it falls into *) and exits with error. Running doctor.sh with no arguments is the intended default mode — it's broken.

Fix: Add ""|--save|--quick) or move the *) after a check for empty $SAVE.

High — Causes Incorrect Behavior

6. echo -e in Wine registry writes HIGH

launcher-functions.sh:324,331,383 use echo -e to write to user.reg. POSIX shells that don't support -e will write literal -e into the registry file, corrupting it. Affects both DPI and browser bridge sections.

Fix: Replace with printf '%b\n' or heredoc.

7. uninstall.sh incomplete HIGH

Leaves ~/.local/share/fusion360-linux/ (runtime scripts), ~/.local/bin/launch-fusion, ~/.local/bin/fusion-doctor, and /tmp/fusion360-dpi.log. Also uses echo -e bashism on line 23.

8. register-protocols.sh stale Exec= path HIGH

Desktop entry Exec=$SCRIPT_DIR/runtime-scripts/fusion-callback-handler.sh but $SCRIPT_DIR resolves to repo root → path becomes src/runtime-scripts/... instead of src/runtime/.... Also: script not reachable during install due to critical bug #1.

9. kill-wine-proton-nuclear.sh stale source path HIGH

SCRIPT_DIR=$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd) → resolves to repo root. Then source "$SCRIPT_DIR/runtime/launcher-functions.sh" — file is at $SCRIPT_DIR/src/runtime/. Path is missing src/ prefix.

10. uninstall-select.sh icon removal partial HIGH

compgen -G "$path" | head -1 in add_comp() stores only the first matching icon path. All but one fusion360.png under hicolor/*/apps/ are left behind.

11. 10-deps.sh unquoted package install HIGH

$INSTALL_CMD $PKGS unquoted — word splitting AND glob expansion. If a package name matches a file in CWD (icoutils? unlikely but wget? possible), wrong arguments are passed. Also no guard for empty PKGS.

12. installer_is_running missing PFX_DIR guard HIGH

00-common.sh:114 uses $PFX_DIR without :- fallback. With set -u, crashes if PFX_DIR somehow unset.

13. No download verification for GE-Proton HIGH

500MB tarball downloaded with no checksum verification. Partial/corrupted download persists and silently blocks re-download — extraction fails with cryptic tar error.

14. load_config cd without error guard HIGH

${VAR:-$(cd "$SCRIPT_DIR/../runtime" 2>/dev/null && pwd)} — if cd fails, default becomes empty string silently, producing broken paths downstream.

Medium — Correctness & Robustness

15. sed -i on user.reg not atomic — SIGINT during sed can leave corrupted Wine registry. Add backup: sed -i.bak.
16. No concurrency guard — Multiple simultaneous install.sh invocations can corrupt the prefix. Add PID file / flock.
17. Predictable /tmp paths — Browser bridge uses hardcoded /tmp/fusion360-* dirs with no mktemp. Symlink attack surface.
18. kill_fusion_processes inverted return — returns 1 on success, 1 on failure. Callers can't distinguish.
19. pre_flight() crashes if df fails — $(( avail_kb / 1024 / 1024 )) with empty avail_kb causes arithmetic syntax error.
20. wget without --timeout — 20-ge-proton.sh and 40-fusion-installer.sh call wget with no timeout. Network hang = script hangs forever.
21. echo -n bashisms — uninstall-select.sh (lines 66, 98) and 40-fusion-installer.sh (line 51). Replace with printf '%s'.
22. exit 0 in pipe-to-while subshell — overlay killer line 172-175: exit 0 inside a pipe-to-while subshell only exits the subshell, not the main script.
23. read without timeout (5 scripts) — install.sh, uninstall.sh, uninstall-select.sh, 40-fusion-installer.sh all block forever on user input in non-interactive contexts.
24. doctor + health-check wrong desktop-file paths — Check parent dir instead of fusion360-linux/ subdirectory.
25. F360_ICONS_DIR dead code — Defined in 00-defaults.sh but never referenced anywhere.
26. declare -a bashism in 37-config.sh — Fine under bash, breaks if ever sourced by /bin/sh.

Low — Style & Cleanup

27. Useless cat in pipes (SC2002) — 00-common.sh:57, 80-logs.sh:39
28. kill -0 → kill TOCTOU race in cleanup() — small window, low risk
29. Config injection via source — inherent design constraint, mitigated by printf %q
30. set -f missing in 10-deps.sh around $PKGS expansion
